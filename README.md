## Working principles

- Separate runnable public evidence from archived or incomplete experiments.
- Keep preprocessing and evaluation reproducible, with fixed seeds and machine-readable outputs.
- Label synthetic data, external services and model limitations directly in the repository.
- Prefer small, inspectable systems over claims that the available artifacts cannot support.
